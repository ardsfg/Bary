# Barycentric Coordinate Calculator

Look in bary.jl for the code. Requires Julia language and MultivariatePolynomials package. 
Complex coordinate calculator also here, though methods are purely computational. 

Problems solved:
2023 USAMO 6; 2008 USAMO 2; half of EGMO Bary section (some with moving points); 2001 USAMO 2; anything with just line intersections. Mainstream computational problems on ARML, PuMAC, CMIMC, AIME, etc.
